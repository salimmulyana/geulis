Dokumentasi API Bridging GeuLIS

Dokumen ini berisi panduan teknis bagi developer SIMRS atau sistem eksternal lainnya untuk berintegrasi secara langsung dengan GeuLIS (Laboratory Information System).

⚠️ Peringatan Keamanan: Semua endpoint di bawah ini memerlukan API Key. Jaga kerahasiaan API Key Anda dengan baik karena ia memberikan hak akses untuk membaca dan mengubah data medis pasien!

1. Autentikasi (Header)

Setiap request wajib menyertakan API Key Anda di dalam Header.

Key (Nama Header) Value (Isi Header) Keterangan
x-api-key khanza_... Kunci rahasia yang di-generate dari menu LIS
Content-Type application/json Bentuk paket data yang dikirim

2. Mengirim Order (Permintaan Lab)

Endpoint ini dipakai SIMRS untuk mengirimkan data pasien beserta daftar periksa lab. Jika pasien belum terdaftar, LIS akan otomatis membuatkannya.

  • URL: /bridging/order
  • Method: POST

Parameter (JSON Body)

Parameter Wajib? Tipe Data Contoh / Keterangan
simrs_order_idYaStringNomor Order dari SIMRS (misal: "ORD-001")
medical_record_noYaStringNomor Rekam Medis (RM) pasien
patient_nameYaStringNama Lengkap Pasien
genderTidakString"L" (Laki-laki) atau "P" (Perempuan). Default: L
birth_dateTidakDateFormat "YYYY-MM-DD"
priorityTidakString"normal", "cito", atau "stat". Default: normal
notesTidakStringCatatan singkat dari dokter pengirim
testsYaArrayKode tes, misal: ["HGB", "LEU", "PLT"]

Contoh Request (JSON Body)

{
  "simrs_order_id": "ORD-20231015-001",
  "medical_record_no": "RM-098123",
  "patient_name": "Budi Santoso",
  "gender": "L",
  "birth_date": "1990-05-15",
  "priority": "cito",
  "tests": [
    "HGB", 
    "LEU", 
    "PLT"
  ]
}

Contoh Kirim JSON via Kode Program

Berikut adalah contoh cara mengirimkan JSON di atas menggunakan bahasa pemrograman umum:

1. Menggunakan PHP (cURL)

<?php
$url = "http://[IP_SERVER_LIS]:3001/bridging/order";
$apiKey = "khanza_CONTOH123gh5678";

$data = array(
    "simrs_order_id" => "ORD-20231015-001",
    "medical_record_no" => "RM-098123",
    "patient_name" => "Budi Santoso",
    "gender" => "L",
    "birth_date" => "1990-05-15",
    "priority" => "cito",
    "tests" => array("HGB", "LEU", "PLT")
);

$ch = curl_init($url);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
curl_setopt($ch, CURLOPT_HTTPHEADER, array(
    "Content-Type: application/json",
    "x-api-key: " . $apiKey
));

$response = curl_exec($ch);
curl_close($ch);

echo $response;
?>

2. Menggunakan Java (HttpURLConnection)

import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;

public class BridgingLIS {
    public static void main(String[] args) {
        try {
            URL url = new URL("http://[IP_SERVER_LIS]:3001/bridging/order");
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setRequestMethod("POST");
            conn.setRequestProperty("Content-Type", "application/json");
            conn.setRequestProperty("x-api-key", "khanza_CONTOH123gh5678");
            conn.setDoOutput(true);

            String jsonInputString = "{"
                + "\"simrs_order_id\": \"ORD-20231015-001\","
                + "\"medical_record_no\": \"RM-098123\","
                + "\"patient_name\": \"Budi Santoso\","
                + "\"gender\": \"L\","
                + "\"birth_date\": \"1990-05-15\","
                + "\"priority\": \"cito\","
                + "\"tests\": [\"HGB\", \"LEU\", \"PLT\"]"
                + "}";

            try(OutputStream os = conn.getOutputStream()) {
                byte[] input = jsonInputString.getBytes("utf-8");
                os.write(input, 0, input.length);
            }

            int code = conn.getResponseCode();
            System.out.println("Response Code: " + code);
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}

3. Menarik Hasil Lab

Endpoint ini dipakai SIMRS untuk mengambil nilai hasil akhir laboratorium yang sudah selesai dikerjakan.

  • URL: /bridging/result/:simrs_order_id
  • Method: GET

Contoh Request

curl -X GET http://[IP_SERVER_LIS]:3001/bridging/result/ORD-20231015-001 \
  -H "x-api-key: khanza_CONTOH123gh5678"

Contoh Balasan (Sukses)

{
  "simrs_order_id": "ORD-20231015-001",
  "request_no": "REQ20231015123456",
  "status": "completed",
  "patient": {
    "medical_record_no": "RM-098123",
    "name": "Budi Santoso",
    "gender": "L",
    "birth_date": "1990-05-15"
  },
  "results": [
    {
      "test_code": "HGB",
      "test_name": "Hemoglobin",
      "result_value": "11.5",
      "unit": "g/dL",
      "reference": "13.0 - 17.0",
      "flag": "L",
      "result_time": "2023-10-15T09:30:00.000Z",
      "status": "completed"
    }
  ]
}
Catatan: Kolom flag berisi indikator nilai (misal: "L" untuk Low/Rendah, "H" untuk High/Tinggi). Jika kosong atau null, berarti hasilnya normal.
