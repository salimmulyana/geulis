1. Cara alat terhubung ke GeuLIS

GeuLIS yang menghubungi alat, bukan sebaliknya. Ini kebalikan dari kebanyakan analyzer. Manual resmi lampiran D.3 menyatakan alat “monitors the message sent by LIS” dan mengirim detak 0x02 tiap 3 detik setelah koneksi terbentuk. 

GeuLIS 192.168.1.14  ──menghubungi──▶  BC-3600 192.168.1.200:3600
                     ◀── detak 0x02 tiap 3 detik
                     ◀── hasil HL7 saat sampel selesai

Karena alat tidak pernah memulai koneksi, di menu alat memang tidak ada isian “IP server LIS” — dan tidak dibutuhkan. Mencarinya hanya membuang waktu.

IP alat192.168.1.200
Port data3600
IP server GeuLIS192.168.1.14
ProtokolHL7 v2.3.1 (MLLP)

Menu Setup → System Setup → Transmission.

Auto retransmitOnkirim ulang setelah jaringan pulih
Auto transmitOnWAJIB — lihat peringatan di bawah
⚠️ Auto transmit adalah penyebab tersering “alat nyambung tapi hasil kosong”.
Perhatikan bedanya dengan Auto retransmit di kotak kanan — itu setting yang berbeda. Auto transmit ada di baris paling bawah layar, sebaris dengan tulisan Whole blood. Manual bagian 5.2.2: bila Off, “the analyzer will not send results to the external computer automatically”.

Langkah untuk petugas lab:

  1. Masuk ke layar Transmission.
  2. Cari baris Auto transmit di bagian bawah.
  3. Tekan lingkaran On.
  4. Keluar lewat menu lain, lalu pilih Yes agar tersimpan.

Aman: setting ini hanya mengatur pengiriman keluar, tidak memengaruhi cara alat memeriksa.

3. Operasional harian

  • Nyalakan: saklar di belakang, inisialisasi 3–5 menit, lalu login.
  • Lampu indikator: hijau menyala = siap; hijau berkedip = sedang jalan; merah menyala = error; merah berkedip = jalan dengan error; kuning = standby.
  • QC dulu, baru sampel pasien. Manual menyarankan QC harian dengan kontrol level rendah, normal, dan tinggi.
  • Volume sampel: whole blood 17 µL, predilute 146,34 µL (dari 20 µL kapiler + 0,38 mL diluen).
  • Tabung: K2EDTA 1,5–2,2 mg/mL.
  • Batas waktu sampel: hitung jenis WBC dalam 12 jam pada suhu ruang, atau 24 jam bila disimpan 2–8 °C (hangatkan dulu 30 menit).
  • Jangan menghitung sampel yang sama lebih dari 3 kali berturut-turut.
  • Matikan lewat menu Shutdown (dengan probe cleanser), wajib setelah alat jalan 24 jam terus-menerus. Jangan langsung cabut listrik.
  • Rendam probe cleanser mingguan — prosesnya 20 menit.

4. Aturan nomor sampel

Salah ketik nomor sampel tidak memunculkan error — GeuLIS malah membuat pasien baru bernama “Pasien <nomor>”. Karena alat tidak bisa menanyakan daftar order ke LIS (protokol HL7 tidak menyediakannya), ketepatan nomor sampel sepenuhnya ada di tangan operator.

Aturan dari manual (bagian 6.6.1):

  • Panjang 1–20 karakter, tidak boleh kosong.
  • Karakter terakhir harus angka.
  • Nomor yang isinya hanya angka “0” dianggap tidak sah.
  • Huruf, angka, dan karakter khusus diperbolehkan.

Nomor sampel harus cocok dengan salah satu dari: nomor rekam medis, nomor order, nomor permintaan, atau ID order SIMRS di GeuLIS.

Tips: alat mendukung bar-code scanner USB (manual 2.3.8 dan B.7.5). Memakai scanner menghilangkan hampir semua risiko salah ketik. Ada 4 port USB di belakang alat. Aktifkan juga Sample ID auto increment di Setup → Auxiliary bila penomoran berurutan.

6. Arti flag dan tanda hasil

TandaArti
H / LDi atas / di bawah nilai rujukan
RHasil diragukan
*****Hasil tidak sah
+++++Di luar rentang tampilan alat
E / eHasil diedit manual / ikut berubah karena editan
R1–R4, RmHistogram WBC abnormal (kemungkinan sel muda, limfosit atipik, dsb)
Pm, PS, PLHistogram PLT abnormal (batas kabur, trombosit terlalu kecil / besar)
  • Bila WBC < 0,5×109/L, alat tidak menghitung jenis leukosit dan semua parameter terkait menjadi *****.
  • Bila PLT < 100×109/L, manual menyarankan pemeriksaan ulang.
  • Flag H/L di GeuLIS dihitung ulang dari nilai rujukan di menu Tes Lab, bukan diambil dari alat. Tes yang terbentuk otomatis belum punya nilai rujukan, sehingga semuanya akan tampak normal sampai rujukannya diisi.

8. Kalau hasil tidak masuk ke GeuLIS

Periksa berurutan:

  1. Ikon komunikasi di layar alat (dekat jam). Berkedip = sedang mengirim, merah = gangguan komunikasi, tidak terlihat = tidak ada pengiriman sama sekali.
  2. Auto transmit sudah On? Ini penyebab paling sering.
  3. Kabel LAN terpasang dan alat menyala.
  4. Di GeuLIS, buka menu Alat — lihat apakah ada baris “koneksi ke 192.168.1.200:3600 terbentuk”.
  5. Coba kirim manual: menu Review di alat, pilih hasil, tekan Transmit. Maksimal 500 record sekali kirim.
Hasil lama tidak hilang. Alat menyimpan 40.000 hasil lengkap dengan histogram. Bila LIS sempat mati, hasil bisa dikirim ulang kapan saja lewat menu Review.
